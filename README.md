# Customer Churn Analysis
An Interactive customer churn analysis project built using Excel, MySQL, and Power BI.
## Project Overview
This project analyzes customer data to understand churn patterns and identify factors associated with customer attrition.
## Key Metrics
- Total Customers: 7,043
- Churned Customers: 1,869
- Churn Rate: 26.54%
## Analysis 
The dashboard explores customer churn across:
- Contract Type
- Internet Service
- Payment Method
- Customer Tenure
  An interactive Churn Slicer was also added to allow users to filter the dashboard by churn status.
## Tools Used
  - Excel
  - MySQL
  - Power BI
